# 설렘과 불안 사이 — 사진 읽기 실험실

중학교 1–2학년 미술 감상·비평을 위한 6단계 웹 학습자료입니다. 개발: 박새롬.

## 수업 목적
연출적 요소가 있는 두 사진에서 색·빛·소품·공간·인물의 배치를 관찰하고, 경험과 배경지식을 연결하여 근거 있는 해석과 판단을 표현합니다. 사진을 설렘/불안의 정답으로 분류하거나 인물의 실제 심리를 추정하지 않습니다.

## 학습 흐름
1. 먼저 느끼기: 사진 A의 첫 느낌 기록
2. 감상과 비평: 감상·비평·미장센, 관찰/해석/판단 구분
3. 근거 찾기: 사진 두 곳 표시, 사실과 해석 연결, 경험과 연결
4. 나란히 보기: A/B의 표현 비교와 효과 판단
5. 시선 나누기: 짝 대화 또는 명시된 가상 관점, 해석 재검토
6. 비평 완성: 자신의 제목, 의미, 근거, 판단, 성찰을 카드로 작성·저장·인쇄

45분 1차시 또는 토론을 확장한 2차시로 운영합니다. 실시간 공동 게시판과 AI 채점은 없습니다.

## 교육과정 근거
`korean-secondary-learning-map-mcp` 0.3.0 서버와 실제 MCP stdio 연결 후 `search_standards(schoolLevel="middle", subject="미술")` 및 코드별 `get_standard`를 호출했습니다. 조회 결과는 `curriculum-evidence.json`에 보존했습니다.

중심 성취기준은 [9미01-01], [9미01-02], [9미03-02], [9미03-03]입니다. 원출처는 교육부 고시 제2022-33호 [별책 13] 미술과 교육과정입니다. MCP 조회일: 2026-11-09.

- [교육부 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)
- [사용한 중등 교육과정 MCP](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp)
- [기반 데이터 DECK6](https://github.com/DECK6/korean-secondary-learning-map)

수록된 공식 자료는 **성취기준**입니다. 자체 질문·자기점검을 공식 **성취수준**으로 제시하지 않습니다. 감상·비평·미장센 설명은 중학생을 위해 작성한 수업용 설명입니다.

## 실행·배포
별도 빌드나 API 키가 없는 정적 HTML/CSS/JavaScript입니다. 정적 서버에서 폴더를 제공하거나 GitHub Pages의 main 브랜치 루트로 배포합니다.

## 학생 기록
응답·사진 표시·진행 단계는 현재 브라우저의 localStorage에 저장합니다. 외부 서버로 전송하지 않습니다. 공용 기기에서는 파일 다운로드 후 수업 안내의 초기화 버튼으로 지웁니다. 저장이 제한된 환경에서는 경고를 표시하며 텍스트 다운로드가 가능합니다.

## 저작권과 출처
`SOURCES.md`를 참조하세요. 사진은 각 작가의 저작물이며 Pexels License를 따릅니다. 전체 저장소에 일괄 MIT 라이선스를 적용하지 않습니다. 사진을 스톡 자료로 재배포하는 목적으로 만든 저장소가 아니라 본 학습 웹사이트의 구성 자산입니다. 인물이나 작가가 자료를 후원한다는 의미는 아닙니다.

## 개발 기록
대화로 수업 목적과 6단계 계획을 확정한 뒤 Codex에서 파일 제작·터미널 검사·브라우저 검증·GitHub 배포를 진행한 대학원 과제입니다. 실제로 실행하지 않은 `/plan`·`/goal` 명령 사용 이력은 주장하지 않습니다. 계획과 검증은 `PLAN.md`, `QA.md`에 기록합니다. 실제 수업 효과는 아직 검증하지 않았습니다.
